ETP কী? 

### Options

### Options
- [x] $\text{CO}+\text{N}_{2}$ 
- [ ] $\text{CO}_{2}+\text{H}_{2}$ 
- [ ] $\text{CO}_{2}+\text{N}_{2}$

ট্রিপল সুপার ফসফেট (টি.এস.পি) এর সঠিক সংকেত কোনটি? 

### Options
- [x] $\text{Ca}(\text{H}_{2}\text{PO}_{4})_{2}$ 
- [ ] $\text{Ca}_{3}(\text{PO}_{4})_{2}$ 
- [ ] $(\text{NH}_{4})_{2}\text{HPO}_{4}$ 
- [ ] $\text{NH}_{4}\text{H}_{2}\text{PO}_{4}$ 

### Explanation
টি.এস.পি (TSP) হলো মূলত পানিতে দ্রবণীয় মনোক্যালসিয়াম ফসফেট। অদ্রবণীয় রক ফসফেটের সাথে অর্থো-ফসফরিক এসিডের বিক্রিয়ায় ট্রিপল সুপার ফসফেট উৎপন্ন হয়:
$\text{Ca}_{3}(\text{PO}_{4})_{2} + 4\text{H}_{3}\text{PO}_{4} \rightarrow 3\text{Ca}(\text{H}_{2}\text{PO}_{4})_{2}$
সাধারণ সুপার ফসফেটের তুলনায় এতে তিনগুণ বেশি দ্রবণীয় ফসফেট থাকে।
