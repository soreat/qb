$\text{AlF}_{3}$ এর দ্রাব্যতা $0.0002\text{ mol/L}$ হলে দ্রাব্যতা গুণফল কত?

### Options
- [ ] $3.4\times 10^{-14}$
- [x] $4.3\times 10^{-14}$
- [ ] $3.4\times 10^{-13}$
- [ ] $4.3\times 10^{-13}$

### Explanation
$\text{AlF}_{3} \rightleftharpoons \text{Al}^{3+} + 3\text{F}^{-}$
দ্রাব্যতা $S$ হলে $K_{sp} = (S)^{1} \times (3S)^{3} = 27S^{4}$
এখানে $S = 0.0002\text{ mol/L} = 2\times 10^{-4}\text{ mol/L}$
$K_{sp} = 27 \times (2\times 10^{-4})^{4} = 27 \times 16 \times 10^{-16} = 432 \times 10^{-16} = 4.32 \times 10^{-14} \approx 4.3 \times 10^{-14}$

$0.005\text{M H}_{2}\text{SO}_{4}$ দ্রবণের $\text{pH}$ কত?

### Options
- [ ] $2.30$
- [x] $2.00$
- [ ] $1.30$
- [ ] $3.00$

### Explanation
$\text{H}_{2}\text{SO}_{4}$ একটি শক্তিশালী দ্বিক্ষারকীয় (Diprotic) এসিড যা জলীয় দ্রবণে সম্পূর্ণ বিয়োজিত হয়ে ২ মোল $\text{H}^{+}$ দেয়।
$[\text{H}^{+}] = 2 \times 0.005\text{M} = 0.01\text{M} = 10^{-2}\text{M}$।
$\therefore \text{pH} = -\log(10^{-2}) = 2$।

$25^{\circ}\text{C}$ তাপমাত্রায় $0.1\text{M CH}_{3}\text{COOH}$ দ্রবণের বিয়োজন মাত্রা ১.৩৪% হলে অ্যাসিডটির বিয়োজন ধ্রুবক ($K_{a}$) কত?

### Options
- [ ] $1.8\times 10^{-4}$
- [x] $1.8\times 10^{-5}$
- [ ] $1.8\times 10^{-6}$
- [ ] $1.8\times 10^{-7}$

### Explanation
বিয়োজন মাত্রা $\alpha = 1.34\% = 0.0134$ এবং ঘনমাত্রা $C = 0.1\text{M}$।
ওস্টওয়াল্ডের লঘুকরণ সূত্রানুসারে দুর্বল এসিডের ক্ষেত্রে:
$K_{a} = \alpha^{2}C = (0.0134)^{2} \times 0.1 = 0.00017956 \times 0.1 = 1.7956 \times 10^{-5} \approx 1.8 \times 10^{-5}$।
